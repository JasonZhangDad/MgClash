# MgClash 1.1.1

> **Unsigned release:** MgClash has no Apple Developer ID, no notarization, no
> Microsoft Authenticode signature, no signed Linux repository, and no GPG
> signature. A checksum is the only integrity check on offer — verify
> `SHA256SUMS`, or the `.sha256` beside your download, before running anything.

## What changed since 1.1.0

1.1.0 shipped as Latest with the new shell still unfinished, and with an Xray
Core that the artifact could not run. That tag is now a pre-release. This
build is the one to use.

- **Xray is in the artifact and the app finds it.** 1.1.0 downloaded and
  verified Xray 26.3.27, then copied only sing-box into the `.app`, the
  installers, and the portable archive. The lookup path and the build-time
  digest existed for sing-box alone, so choosing Xray failed with
  `xray_unavailable`. 1.1.1 copies Xray (and the geo databases it needs to
  start) and resolves it the same way it resolves sing-box.
- **Routing is the rule table the shell was designed around.** The page is no
  longer a stacked “pick a type, fill a value, click add” form. Rules are a
  grid with a drag handle, a type badge, the value, the outbound, a per-row
  switch, and a ⋯ menu. Rule sets are their own table: name, URL, format,
  outbound, cache, and a cached / pending badge.
- **DNS is two cards.** Basic holds the resolver mode, server, address
  strategy, and IPv6. Advanced holds Fake-IP, bootstrap, system-resolved
  names as chips, plus DoH path, hosts, and port. Every row has a short
  explanation. The side card still shows what is in effect and offers save
  and restart.

The rest of the 1.1.0 shell is unchanged: sidebar pages, Connect in the top
bar, command palette, traffic history, and the same capabilities.

Every download here is built from one commit.

A cross-platform desktop proxy client that drives external Cores. It implements
no proxy protocol itself: sing-box and Xray do the work, and MgClash decides
which one can run a node, generates its configuration, and manages its
lifecycle.

## What it does

- **Nodes**: VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, SOCKS5, HTTP,
  WireGuard, AnyTLS, Naive, and raw custom Core configs. Import by share link,
  by file, by QR image, or with the camera; export the same way.
- **Subscriptions**: scheduled updates, include/exclude filters, a custom
  User-Agent, and subconverter support.
- **Routing**: rule / global / direct modes, named schemes, and rules matching
  domain, suffix, keyword, IPv4 and IPv6 CIDR, port, network, sniffed protocol,
  inbound, process name and path, GeoIP/GeoSite, and remote rule sets.
- **DNS**: system, UDP, TCP, DoH, DoT, address strategies, hosts, and FakeIP.
- **Local proxying**: SOCKS and HTTP inbounds, optional LAN exposure, System
  Proxy in managed / PAC / cleared / unchanged modes, with the host's previous
  proxy state snapshotted and restored.
- **TUN** on all three platforms, behind the desktop's own authorization prompt.
- **Live status**: Clash-API traffic and connections, latency and download speed
  tests, policy groups with automatic re-measurement, a log panel, and a
  redacted diagnostic bundle.
- Ten interface languages, global hotkeys, and a tray.

## Platform warnings

- **macOS** Gatekeeper will warn on first launch; open the app explicitly
  through Finder or System Settings. TUN asks for administrator authorization
  when you enable it — macOS opens a `utun` device for root only. Stopping a TUN
  session asks a second time, because the app cannot signal a process it does
  not own.
- **Windows** SmartScreen will warn for both the portable executable and the
  installer. Select **More info → Run anyway** only after verifying the
  checksum. TUN asks for UAC elevation.
- **Linux** ships as a tarball rather than through a signed package repository.
  TUN asks through polkit and needs a running authentication agent.

## Bundled

The official **sing-box 1.13.18** and **Xray 26.3.27** Cores are included and
pinned by SHA-256. Xray also carries `geoip.dat` and `geosite.dat`; without
them a geoip:/geosite: rule refuses to start. Windows also includes the
official Authenticode-verified **Wintun 0.14.1** driver library.

Downloading a newer Core from within the app verifies it against the digest its
publisher ships, or — for sing-box, which publishes none — records the first
download's digest and refuses a later one that disagrees.

## Known limits

- Nothing here is signed. On every platform the OS will treat it as software
  from an unidentified developer. On macOS that means a double-click is refused
  until you either right-click the app and choose **Open**, or clear the
  quarantine flag with `xattr -dr com.apple.quarantine /Applications/MgClash.app`.
- **The default ports collide with most other proxy clients.** MgClash listens
  on SOCKS 10808 and HTTP 10809, which is exactly what v2rayN and its relatives
  use. If one of those is already running, connecting fails with
  `local Socks proxy port 127.0.0.1:10808 is unavailable: Address already in use`.
  Change the ports in Settings → Network, or stop the other client first.
- The authorization prompts, camera scanning, and real TUN traffic are verified
  by hand rather than by the test suite; automated coverage stops at the
  boundary where a human has to approve something.
- A saved config override is used verbatim and does not follow a later change of
  node or route. The window says so while one is in force.
- The interface is verified by unit and component tests, a type check, and a
  release build. It has not been through a hands-on pass on Windows or Linux —
  layout at the 1100×700 lower bound in particular is untested on those two.
- Traffic history starts accumulating at first launch of 1.1.0. Upgrading from
  1.0.x does not backfill earlier days, because no per-day totals were kept
  before 1.1.0.
