# MgClash 0.1.0

> **Unsigned release:** MgClash has no Apple Developer ID, notarization,
> Microsoft Authenticode signature, Linux repository signature, or GPG
> signature. Verify `SHA256SUMS` before running any download.

This V0.1 release provides local HTTP/SOCKS proxying, System Proxy management,
node and subscription management, DNS and route modes, traffic and latency
status, diagnostics, and bounded Core recovery.

## Downloads

- macOS Intel: `mgclash-0.1.0-macos-x86_64-unsigned.tar.gz`
- macOS Apple Silicon: `mgclash-0.1.0-macos-aarch64-unsigned.tar.gz`
- Windows portable: `mgclash-0.1.0-windows-x86_64-unsigned.zip`
- Windows installer: `mgclash-0.1.0-windows-x86_64-unsigned-setup.exe`
- Linux: `mgclash-0.1.0-linux-x86_64-unsigned.tar.gz`

Every download has an individual `.sha256` sidecar. `SHA256SUMS` covers the
complete release set.

## Platform warnings

- macOS Gatekeeper will warn on first launch. Open the app explicitly through
  Finder or System Settings. TUN is unavailable in this unsigned build because
  it cannot carry Apple's Network Extension entitlement.
- Windows SmartScreen will warn for both the portable executable and installer.
  Select **More info → Run anyway** only after verifying the checksum.
- Linux is distributed as a tarball rather than through a signed package
  repository. TUN requires `CAP_NET_ADMIN`.

The official sing-box 1.13.18 Core is included and pinned by SHA-256. Windows
also includes the official Authenticode-verified Wintun 0.14.1 driver library.
